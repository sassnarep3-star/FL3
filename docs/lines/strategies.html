Strategies & Signals

Research-based framework for generating useful NFL betting signals. Each strategy must pass the validation gates on the Validation Gates page. Correlation values are determined per strategy (see Suggestion S04); luck is removed via CLV and luck-adjusted metrics (see the Validation Gates and Leaderboard pages).

Strategy rules

IDRuleDescriptionSourcesFlag
SR01Edge qualification ruleA bet is flagged only when its edge clears the minimum threshold AND its expected value per dollar clears the minimum EV threshold. Thresholds are set in advance via validation gates and are not tuned to results.
https://github.com/jcollins901/nfl-edge
SR02Grade-based screeningEdge values are graded (e.g., >=2.5% ~ A, 0.5-2.5% ~ B, -0.5-0.5% ~ C, -2.5--0.5% ~ D, below -2.5% ~ F); only grades at or above the chosen cutoff are eligible.
https://beatabookie.com/nfl-betting-101-how-pff-discovers-and-defines-edges-nfl-and-ncaa-betting-picks/
SR03Selective skill-based deploymentStrategies deploy only on games/markets where the composite signal is strongest; low-confidence games are skipped. Selectivity reduces variance and concentrates edge, making results measurable as skill rather than luck.
https://www.sharkbetting.com/blog/closing-line-value-clv-explained
