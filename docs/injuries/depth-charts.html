Depth Charts

The system must track injuries and know deficiencies when 2nd/3rd/4th-string backups replace starters on offense and defense. The framework below defines detection rules and data sources. Depth ORDER is not machine-verifiable from NFL.com (depth-chart page returns 404), so all depth-order cells are intentionally blank and flagged; only roster STATUS (ACT/DEV/PUP/TRD) is verifiable from the official roster pages.

Detection framework

DC01Injury detectionPull the official NFL.com injury report each week; parse player, position, injury designation, practice participation, and game status (Out / Doubtful / Questionable / no designation).Implemented — verified data collected for Week 10, 2026 (345 rows).
https://www.nfl.com/injuries
DC02Roster status detectionPull the official NFL.com team roster pages; parse each player's status (ACT = active, DEV = developmental squad, PUP = physically unable to perform, TRD = traded, IR = injured reserve).Verified — roster page structure confirmed against Kansas City Chiefs official roster.
https://www.nfl.com/teams/kansas-city-chiefs/roster
DC03Starter/backup identificationCompare the official injury report against the official roster: a starter-level absence means the next depth chart player (2nd string) is expected to start; a 2nd-string absence pushes the 3rd string in, and so on down to 4th string.Pending — depth ORDER is not machine-verifiable from NFL.com (depth-chart page 404s); flagged for manual review (FL02).
https://www.nfl.com/injuries
DC04Deficiency scoringScore the expected performance drop per position group when a backup replaces a starter, using Adjusted Games Lost (AGL) methodology: starters are weighted more heavily than bench players, and weekly game-status health is incorporated.Framework defined — AGL values per team not yet collected (data gap).
https://www.sharpfootballanalysis.com/betting/numbers-that-matter-for-predicting-win-totals-part-two/
DC05Offense and defense coverageApply the same detection and scoring to both offense (QB, RB, WR, TE, OL) and defense (DL, LB, CB, S) so lineup deficiencies are tracked on both sides of the ball.Framework defined.
https://www.nfl.com/injuries
DC06Signal integrationFeed deficiency scores into the injury-adjusted signal (SG06); any strategy deployed on a game with confirmed starter absences must apply the adjustment (validation gate VG06).Framework defined — wired to validation gate VG06.
https://www.sharpfootballanalysis.com/betting/numbers-that-matter-for-predicting-win-totals-part-two/
