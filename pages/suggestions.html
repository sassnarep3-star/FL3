Suggestions

This is the dedicated register where improvement proposals are collected so a reviewer can weigh options and choose the best path before any change is implemented. Nothing in this table has been executed beyond writing the proposal itself. Each row states the expected benefit, what would change, and the official source the idea relates to, so the review can be done from evidence rather than assertion.

Review workflow. PROPOSED Awaiting reviewer decision. ACCEPTED Approved — an owning session may claim it in COORDINATION.md. REJECTED Declined — reason recorded here. Decisions should be recorded on this page and in the coordination log, creating an auditable change trail.
