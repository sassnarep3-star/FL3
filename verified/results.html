Results — 148 verified games

Every row is transcribed from an official NFL.com weekly schedule page that renders the game as FINAL. A game that was in progress or not yet played is not a result and is not in this file. The whole corpus is checked against the league standings before publication.

Why this file exists. No previous build in this repository had enough verified results to compute a proper score. One held 33 rows against a 137-game season; the rest held none. Without results, a leaderboard is decoration. The check that makes it trustworthy: for all 32 clubs, wins, losses, ties, points-for and points-against summed from these 148 rows reproduce the official standings page exactly — 160 figures, no tolerance, no fudge factor. A single transposed score would fail it. Re-runnable with python3 scripts/build_week_results.py --check.
