NFL 2026 — verified data, originated lines, honest scoring

Eleven weeks into the 2026 season. The schedule pages now publish final scores for 148 games, and those rows reconcile exactly against the league's own standings. That is enough to score this project's own predictions out of sample — which is done below, including where the answer is "no demonstrated skill".

The single most important line on this site. The registered baseline does not beat a pick'em line at a 95% confidence level over 100 out-of-sample games, and its win probabilities are not distinguishable from a coin flip. Detailed numbers are below and nothing on this page is phrased as if that were not the case. What is established is the measurement apparatus: a result corpus that reconciles to the league's own arithmetic, a frozen pre-registration, and a scoring path that would detect skill if it appeared.

Blocked, and why

  • No licensed price. No NFL page publishes a spread, total or prop price. Closing-line value and realised return cannot be computed for any strategy here. This is a fact about the sources, not a gap in the work.
  • No official depth ordinal. The league publishes rosters and injury reports, not depth ranks. Backup depth is a model estimate on third-party chart data and is labelled as such everywhere.
  • No snap counts or inactive lists. A backup replacing a starter can be identified, but that the backup played the starter's snaps cannot be evidenced from an official league page.
  • No dated injury archive. The official page overwrites each day's designations, so a practice trend cannot be reconstructed after the fact — only captured prospectively.

What this is. A verified-data dashboard. Official league values carry a source link. Model output is labelled model output. No licensed betting price exists in this repository, so closing-line value and realised return are not computed and not implied anywhere.

Every page here is generated from the committed data files by scripts/build_verified_site.py and re-checked by scripts/check_verified_site.py. Other dashboards in this repository (root, board, docs, depth, site-9b181d31) are separate builds and are not superseded by this one.
