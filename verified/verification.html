Each is re-checked here against the live official page and given one of five outcomes. The stale ones and the ones that exonerate the repo are published with exactly the same prominence.

Source gaps — questions no official page can answer

These are the rows where the honest answer is "there is no official source". They are listed here so that no downstream page can quietly imply otherwise.

  • LV-09 — An official NFL source publishes a depth-chart ordinal that could rank a player as 2nd/3rd/4th string.
    NFL.com publishes rosters and injury reports but no depth-chart ordinal; club depth pages are club-published, not league-published, and several clubs publish an image rather than a table. There is no official league URL that settles a 32-club depth ranking. This row therefore cannot be marked confirmed and must not be presented as if it had been.
  • LV-10 — An official, licensed market price for spreads, totals or props is available to this repo.
    No NFL-operated page publishes a betting price. Sportsbook pages are operator-published, not league-official, and are geo-gated or non-machine-readable from this environment. There is no official URL for this row.
  • LV-11 — Snap counts and official inactive lists are captured, so a backup replacing a starter can be confirmed rather than suspected.
    The league injury report publishes practice and game designations but not snap counts and not the 90-minute inactive list. No official machine-readable snap-count feed is registered.
  • LV-12 — The Week 10 injury report can be reconstructed as a daily series (Wed/Thu/Fri practice progression).
    The official League injury page renders one current report per week, overwriting the previous day's designations. There is no dated archive URL for the Wednesday or Thursday version of the Week 10 report.
  • LV-13 — A club depth chart is a durable statement of who will start.
    Club depth pages carry no league-issued version or effective date, so there is no official reference point against which to prove a chart is current. A chart cannot be shown to be stale from an official source alone.

What this session changed, and what it deliberately did not

Added

  • A 148-game results corpus that reconciles to the official standings.
  • An out-of-sample evaluation of the repo's own committed Week 10 lines, with the contaminated game excluded.
  • A walk-forward baseline over the full corpus with game-cluster intervals and explicit baselines.
  • This register, the pre-registration, and a single deploy path.

Not touched

  • No other session's data file was edited. Where a defect was found, it is reported here with its evidence and left for its owner.
  • No value was filled in from memory, inference or a third-party aggregator.
  • No merge was made against a failing check.

What this is. A verified-data dashboard. Official league values carry a source link. Model output is labelled model output. No licensed betting price exists in this repository, so closing-line value and realised return are not computed and not implied anywhere.

Every page here is generated from the committed data files by scripts/build_verified_site.py and re-checked by scripts/check_verified_site.py. Other dashboards in this repository (root, board, docs, depth, site-9b181d31) are separate builds and are not superseded by this one.
