Our originated lines

Lines produced by a model in this repository, not copied from a sportsbook. Each carries its inputs and an uncertainty band. The market column is deliberately empty: no licensed price exists in this repo, so an edge cannot be claimed and is never displayed as if it could.

These are not picks. No strategy on this site risks money, and the model holding them does not beat a pick'em line at 95% confidence (see Overview). They are published because a forecast that is not recorded before kickoff cannot be scored, and an unscored forecast is not evidence.

Why there is no "edge" column

An edge is model price minus market price. This repository holds no market price. Every previous build that displayed market columns either left them blank or filled them from an operator's public page, which is not an official league source and is not licensed for redistribution. The honest presentation is a blank market column and a stated reason — which is what is here.

What this is. A verified-data dashboard. Official league values carry a source link. Model output is labelled model output. No licensed betting price exists in this repository, so closing-line value and realised return are not computed and not implied anywhere.

Every page here is generated from the committed data files by scripts/build_verified_site.py and re-checked by scripts/check_verified_site.py. Other dashboards in this repository (root, board, docs, depth, site-9b181d31) are separate builds and are not superseded by this one.
