# FL3 — NFL Lines Research & Decision Dashboard

FL3 collects, organizes, and analyzes NFL data to generate original NFL betting lines and
support evidence-based decisions.

## What this project does

- **Original NFL lines** — builds line-generation strategies (single bets, parlays, player-prop
  combinations) and treats strategy performance as a **leaderboard competition** with rewards for
  top-performing strategies.
- **Validation gates** — every strategy must pass fixed gates (edge, EV, sample significance,
  walk-forward, correlation, injury adjustment, luck-adjusted scoring) before it can score or earn
  rewards.
- **Correlation values** — signal families are correlated and multi-leg bets are priced jointly;
  correlated legs never use naive probability multiplication.
- **Luck removal** — performance is measured with closing line value (CLV) and luck-adjusted
  efficiency, not raw win/loss.
- **Injury & depth tracking** — tracks the official NFL injury report and roster status to detect
  when 2nd/3rd/4th-string backups replace starters on offense and defense, and scores the
  resulting deficiencies.
- **Decision support** — a dedicated Suggestions section and a Questions & Answers page list the
  information that must be addressed before any decision; a Flagged for Review page publishes
  every unverified or irregular item with its source links.

## Verification policy

Every table row on the site carries a source link to an official site. Values that cannot be
confirmed from an official source are **left blank and flagged as unverified** — never inferred.

## Site (GitHub Pages)

The static dashboard is generated by `build.py` from the JSON data in `data/` and is served from
`docs/` via GitHub Pages.

- Landing page: `docs/index.html` — dashboard hub with verified-data counts and category navigation.
- Subpages organized by category: Overview (Executive Summary), Decisions (Questions & Answers,
  Suggestions), NFL Lines (Strategies & Signals, Validation Gates, Leaderboard, Market Data),
  Injuries (Injury Report, Depth Charts), League Data (2026 Standings), Review (Repo Review,
  Flagged for Review).

## Repository layout

```
COORDINATION.md    Shared task board (sessions, task status, verification & integration logs)
build.py           Site generator — renders docs/ from data/*.json
data/              Single source of truth (JSON). Every row carries source links.
  standings.json       2026 NFL standings (32 teams) — NFL.com
  injuries.json        Week 10, 2026 injury report (345 rows) — NFL.com
  lines.json           Week 10 lines (blank + flagged; official book links)
  questions.json       Decision prerequisites
  suggestions.json    Suggestions & review workflow
  strategies.json      Signal families & bet-type strategies
  validation.json      Validation gates
  leaderboard.json     Leaderboard scoring, rules, reward tiers
  depth.json           Injury/depth-chart deficiency framework
  review.json          Repo audit & flagged items
docs/              Generated static site (GitHub Pages output)
```

## Build

```bash
python3 build.py
```

Regenerates `docs/` from `data/`. Commit the generated `docs/` so Pages serves the latest build.
