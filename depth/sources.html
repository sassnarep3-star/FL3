Authority rules

  • Game availability (Out / Doubtful / Questionable) comes ONLY from S02. Ourlads O/Q flags in S04 are treated as unverified inputs and every disagreement is logged in the flagged register.
  • Depth ORDER comes from S04 only.
  • Draft pedigree comes from S04 codes decoded with S05.
  • Every number in data/*.json carries a src field pointing at one of these IDs.

Verification performed

An automated harness (scripts/verify_depth.py) runs on every build and fails it if any of the following break. All 16 checks pass as of 2026-11-14:

  • Balance identity — sum of points-for equals sum of points-against across all 32 teams (6,291 each).
  • Formula reproduction — all 32 winning percentages recompute exactly from their own W-L-T record.
  • Arithmetic coherence — all 32 net-points totals equal PF − PA.
  • Schedule completeness — 14 games, 28 distinct teams, 4 byes, 32 accounted for, no team twice.
  • Controlled vocabulary — every injury practice and game status is one of the values the league publishes.
  • Source totality — every data row carries a source id that resolves to a registry entry.
  • No odds leakage — the line file is scanned for market/price fields and must contain none.
  • Line coherence — every published total and line recomputes from its own published components.
  • Gate completeness — every strategy carries every validation gate.
  • Honesty invariant — no open question may carry an answer; the leaderboard may not contain an unbacked row.
