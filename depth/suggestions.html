Detail

S-01 · Publish a one-line provenance tag on every figure implemented

Impact 5/5 · Effort 2/5 · Confidence 95%
Problem
A dashboard that mixes verified and assumed numbers is worse than no dashboard, because readers cannot tell which is which.
Proposal
Every table row links to its source. Any value that could not be verified is blank with a visible 'unverified' marker.
Evidence
Implemented in scripts/verify.py, which fails the build on a blank source id.
Decision
Accepted and implemented this session.

S-02 · Separate availability from depth ordering implemented

Impact 5/5 · Effort 2/5 · Confidence 95%
Problem
Ourlads and nfl.com disagreed 14 times in a single week. Merging them silently produces a confidently wrong answer.
Proposal
Official NFL report owns availability. Ourlads owns depth order. Disagreements are published, not averaged.
Evidence
data/depth_risk.json -> conflicts (14 rows, C-001..C-014).
Decision
Accepted and implemented. Awaiting reviewer confirmation (Q-05).

S-03 · Ship an empty leaderboard instead of a fabricated one implemented

Impact 4/5 · Effort 1/5 · Confidence 99%
Problem
A seeded leaderboard with plausible-looking ROI is the easiest way to make the whole project untrustworthy.
Proposal
Show the gate machinery and state plainly that no strategy has been graded.
Evidence
data/strategies.json -> leaderboard.rows is [].
Decision
Accepted and implemented.

S-04 · Pre-register the skill thresholds before seeing results proposed

Impact 5/5 · Effort 1/5 · Confidence 90%
Problem
Thresholds picked after the results are not evidence, they are curve-fitting.
Proposal
Ratify the luck-removal pass rules (L1, L4, L5 + bootstrap) now, in writing, before any bet is graded.
Evidence
Q-08 asks for exactly this sign-off.
Decision
Deferred to the user. This is the highest-value five-minute action available.

S-05 · Get one timestamped closing line before building anything else proposed

Impact 5/5 · Effort 3/5 · Confidence 90%
Problem
Four strategies and the entire leaderboard are blocked on the same missing input.
Proposal
Obtain a licensed odds source. It unblocks G4, STR-08, CLV, and any market-comparison page.
Evidence
Rejected/unavailable list in data/sources.json; Q-04.
Decision
Deferred - requires a decision only the user can make.

S-06 · Replace draft pedigree with snap counts in the exposure index proposed

Impact 4/5 · Effort 3/5 · Confidence 80%
Problem
Pedigree measures draft status, not current ability.
Proposal
Swap the pedigree weight for a snap-share weight once snap data exists. Keep the formula shape, change one input.
Evidence
known_weaknesses in data/lineup_risk.json; Q-12.
Decision
Deferred.

S-07 · Add a staleness banner driven by the as-of date implemented

Impact 3/5 · Effort 1/5 · Confidence 95%
Problem
Static pages silently become wrong.
Proposal
Every page prints the capture date and warns when the data is older than 7 days.
Evidence
docs/*.html header block.
Decision
Accepted and implemented.

S-08 · Treat reported injury status as missing data, not as 'healthy' implemented

Impact 4/5 · Effort 1/5 · Confidence 95%
Problem
107 transcribed players carry no official designation. Calling them healthy would invent 107 facts.
Proposal
A third state, 'no designation published', distinct from both Out and playing.
Evidence
data/depth_risk.json -> no_designation_published.
Decision
Accepted and implemented.

S-09 · Score the leaderboard on risk-adjusted, deflated returns implemented

Impact 4/5 · Effort 2/5 · Confidence 85%
Problem
Ranking by raw ROI rewards the luckiest high-variance strategy.
Proposal
Rank on ROI/stdev, deflated for the number of strategies tried.
Evidence
data/strategies.json -> leaderboard.reward_scheme.
Decision
Accepted as a design. Not yet exercised because no bets are graded.

docs/index.html plus category pages.
Decision
Accepted and implemented.
