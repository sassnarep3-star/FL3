How the line is built

  1. Ratings. Each club gets an offence and defence rating from official PF/PA per game, shrunk toward league average by a two-game prior.
  2. Expected scores. Away expected = (away offence + home defence) / 2; home expected = (home offence + away defence) / 2. Home-field is +1.9 points.
  3. Availability. Missing offensive players lower that club's expected points; missing defensive players raise the opponent's. Specialists move both slightly. Each bucket is capped.
  4. Uncertainty. Sigma grows with sqrt(1 + 8 / games played). Fewer games, wider band, on purpose.
  5. Win probability. Normal CDF of the margin against that sigma. No threshold, no rounding to a "key number".
